# Print

`artifacts/print.png` is a 1024 × 1024 PNG (`image/png`). Three articulated violins brandish their bows as carnival-colored ribbons spiral around a black hole. The carnival styling interprets “zillyhooesque.”

“Pepe” was treated as a reference to a copyrighted character and omitted under the brief’s exclusion rule. Visual inspection found no lettering or other unmet visual requirements. PNG chunk checksums and compressed image data were verified.
